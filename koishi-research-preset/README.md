# 研究预设

为 koishi 的数学与理论物理研究提供紧凑研究指令、独立复核、精选技术技能和可追溯计算结果。兼容 DeepSeek Harness `0.2.1-rc.2`。

> **按自己的环境调整后再使用。** 本包保留 koishi 的个人设定，包括私人笔记绝对路径及本机数学／TeX 工具环境说明。实际使用时，请在 DSH **创造模式**下根据自己的研究需求、笔记位置、MCP 与本机工具进行检查、调整和测试，不要原样相信这些环境断言；创造模式不等于权限或沙箱模式。见[仓库首页](<../README.md>)。本包不附送私人笔记、数学 MCP 服务端或计算内核。

## 使用

通过 Harness 插件管理器安装本目录，新建会话并选择 **研究预设**（`koishi-research`）。内置预设、默认模型、权限、实验性插件开关和现有 MCP 服务端保持原样。旧会话保留原预设修订，不用来验证新配置。

- 研究 persona 在 [persona.md](<persona.md>)；不加载 `dsh-agent-instructions`，因而不自动注入全局指令。具体文件的局部规范按需读取。
- 技能目录独立隔离，仅包含 `math-computation`、`paper-reading`、`latex`。原来的 Skills 管理器仍管理原有全局技能，而非这个包的私有目录。
- 复用原有数学 MCP、文件、网页、后台计算和普通子代理能力。子代理默认继承当前路由与预设，最大委派深度为 1。任务管理及环境管理工具不进入研究工具集。
- 历史检索若已由用户开启则正常继承；本包不改变该开关。

## 计算证据

仅五个现有数学 MCP 工具的已识别成功返回会经过 `math-results`：先保存已收到的原始值和文本，再生成紧凑展示；canonical value 和执行状态不变。警告、未求值、规范化流程、显式条件和截断标记仍展示。运输成功不被改写为数学证明。

数据保存在 `$DSH_HOME/research-results`（`DSH_HOME` 未设置时使用 `~/.dsh/research-results`），按会话分隔，私有权限，不自动清理。每次投影返回原始 JSON 和分行阅读视图的定位；JSON 是机器可重载记录，分行视图是阅读辅助。

保存的是 **服务器实际返回的数据**。服务器先行截断的表达式不能靠详情恢复；需要全文时按内核配方复算并直接导出。MCP 抛出的错误、未知结构、其他策略已改写的内容、取消及存储失败都保持原返回，不自动重跑。通用 Host spill 仍按原设置工作。

## 长对话

v0.2.0 使用“研究检查点＋短尾＋按需证据”。研究摘要继承官方 `BasicCompactionEngine`，仅替换 `summarize()`；事务、自动触发、配对、恢复与原始日志机制不重写。不挂载工具结果中段裁剪器。

自动触发比例保持 0.75，余量 16384；用 `retainTokens: 8192` 替代窗口比例保留。8192 是估算的最低尾部预算，不是精确 token 数或硬上限：完整消息／工具配对可能导致超额。旧编辑参数、已完成的读取和计算输出主要被覆盖为检查点，不按角色粗暴删除。

检查点正文目标 `summaryTargetChars: 6000`，连同机器附加的证据入口最多 `summaryMaxChars: 12000` 个 UTF-16 单元（不含宿主固定检查点外壳）。摘要模型调用仍用 `maxTokens: 32768`，包含提供商计入的推理；压缩/溢出重试仍各 1 次。摘要长度预算与模型 token 预算分开；超长、不完整、非文本或取消的摘要不替换历史，不截断公式来凑数。

检查点保存当前问题、必要定义与约定、关键公式及条件、核验范围、失败分支、当前断点和少量关键来源。旧检查点合并更新，反复编辑只记最终状态与理由，不复制历次 `old_string/new_string`。支持 `/compact`；它与自动压缩的保留路径不同。

### 按需读回

每次生成检查点前，在同一个私有证据库保存本段的事件索引与分段 JSONL 阅读副本。原始 Session 日志仍是事实来源；副本仅包含可读正文、工具参数／结果和附件引用，不复制系统／开发者提示、推理块、流记录或 provider 私有回放状态，不复制附件本体。

索引给出准确会话 ID、事件序号和 JSONL 行范围；事件序号按 surface 顺序列出，不假设数值连续。JSONL 首行为 schemaVersion 1 的 header；字符串为 chunk 行，按 `(eventSeq, blockIndex, field)` 分组，再按从 0 开始的 `part` 连接 `text` 恢复原字符串，每段不超过 200 个 UTF-16 单元且不拆 surrogate pair。value 行保存布尔／数值元数据，message 行划分消息。

检查点附 `历史事件索引` 和 `历史分段原文` 两个实际文件定位。先读索引，再 `read` 对应行的小分页（例如 `limit: 10`）；需要时顺着旧检查点中保存的上一代入口继续读，勿把整个档案重新塞回上下文。已有会话检索工具也可按准确序号读原事件；本包不启用或依赖该开关。旧文件快照不能代替编辑前重新读取当前文件。

定位不唯一、存储失败、摘要超限或取消时，本次不提交替换；可能留下未被检查点引用的私有阅读副本。读取权限被拒绝、文件缺失或附件不可恢复时必须报告，不绕过权限或猜测原文。压缩效果应看后续正常请求的实际输入 usage；即时界面投影与估算分类不是实际 token 分解。

## 开发与测试

纯逻辑测试使用 Node 内置测试框架，无第三方测试依赖：

```sh
node --test tests/*.test.js
```

Host 模块通过公开的 Cordis Loader API 复用已安装的 Harness 模块与类身份；不从本地链接目录裸导入内置包，也不安装另一份 Harness SDK。包内没有安装或自动构建钩子。图标是本包原创，重建脚本使用 Pillow。

安装应使用 `plugin_manager` 的 `install_bundle`，不手改 profile 清单。v0.2.0 的既有本机验收中，独立合成研究样本经两次真实自动压缩后，正常请求实际输入占窗口约 **4.8%**；冷恢复与跨代索引读回通过。共 93 项单元测试、352 条本轮运行时断言；公开摘要及失败记录见 [验证记录](<VERIFICATION.md>)。这些实机测试未在本次发布同步中重跑，也不是任意会话保证：巨型不可拆工具组可超出尾部预算；摘要传输失败则保留原历史，不提交残缺检查点。

管理工具隔离监听公开的注册变化事件，避免冷启动时晚注册工具漏出。修改已加载的本地 preset 源码可能触发宿主的待重载限制；以 Plugin Manager 的应用结果及新会话验证为准，不操作私有缓存。回滚通过 Plugin Manager 停用或换回旧版 bundle，保留聊天和计算产物，不切换其他功能。

公开仓库不包含私人实机探针和原始验收产物。为使上述单元测试能独立运行，三个纯夹具检查函数逐字提取到[测试辅助模块](<tests/fixture-helpers.js>)，仅调整[夹具测试](<tests/fixture.test.js>)的导入；生产代码与本地新版保持一致。
