# 研究预设

为 koishi 的数学与理论物理研究提供紧凑研究指令、独立复核、精选技术技能和可追溯计算结果。兼容 DeepSeek Harness `0.2.1-rc.2`。

> **按自己的环境调整后再使用。** 本包保留 koishi 的个人设定，包括私人笔记绝对路径及本机数学／TeX 工具环境说明。实际使用时，请在 DSH **创造模式**下根据自己的研究需求、笔记位置、MCP 与本机工具进行检查、调整和测试，不要原样相信这些环境断言；创造模式不等于权限或沙箱模式。见[仓库首页](<../README.md>)。本包不附送私人笔记、数学 MCP 服务端或计算内核。

## 使用

通过 Harness 插件管理器安装本目录，新建会话并选择 **研究预设**（`koishi-research`）。内置预设、默认模型、权限、实验性插件开关和现有 MCP 服务端保持原样。旧会话保留原预设修订，不用来验证新配置。

- 研究 persona 在 `persona.md`；不加载 `dsh-agent-instructions`，因而不自动注入全局指令。具体文件的局部规范按需读取。
- 技能目录独立隔离，仅包含 `math-computation`、`paper-reading`、`latex`。原来的 Skills 管理器仍管理原有全局技能，而非这个包的私有目录。
- 复用原有数学 MCP、文件、网页、后台计算和普通子代理能力。子代理默认继承当前路由与预设，最大委派深度为 1。任务管理及环境管理工具不进入研究工具集。
- 历史检索若已由用户开启则正常继承；本包不改变该开关。

## 计算证据

仅五个现有数学 MCP 工具的已识别成功返回会经过 `math-results`：先保存已收到的原始值和文本，再生成紧凑展示；canonical value 和执行状态不变。警告、未求值、规范化流程、显式条件和截断标记仍展示。运输成功不被改写为数学证明。

数据保存在 `$DSH_HOME/research-results`（`DSH_HOME` 未设置时使用 `~/.dsh/research-results`），按会话分隔，私有权限，不自动清理。每次投影返回原始 JSON 和分行阅读视图的定位；JSON 是机器可重载记录，分行视图是阅读辅助。

保存的是 **服务器实际返回的数据**。服务器先行截断的表达式不能靠详情恢复；需要全文时按内核配方复算并直接导出。MCP 抛出的错误、未知结构、其他策略已改写的内容、取消及存储失败都保持原返回，不自动重跑。通用 Host spill 仍按原设置工作。

## 长对话

研究摘要继承官方 `BasicCompactionEngine`，仅替换 `summarize()`；事务、配对、恢复与原始日志机制不重写。不挂载工具结果中段裁剪器。

配置：自动压缩，触发比例 0.75，最近尾部预算比例 0.25，余量 16384，摘要预算 32768，压缩/溢出重试各 1 次。比例依当前路由的实际窗口和输出预留计算，不是对任意模型容量的声明。支持 `/compact`。摘要中保留定义、约定、关键公式、成立条件、核验范围、失败分支和证据定位；不完整摘要不能替换历史。

## 开发与测试

纯逻辑测试使用 Node 内置测试框架，无第三方测试依赖：

```sh
node --test tests/*.test.js
```

Host 模块通过公开的 Cordis Loader API 复用已安装的 Harness 模块与类身份；不从本地链接目录裸导入内置包，也不安装另一份 Harness SDK。包内没有安装或自动构建钩子。图标是本包原创，重建脚本使用 Pillow。

安装应使用 `plugin_manager` 的 `install_bundle`，不手改 profile 清单。具体测试结果见 [验证记录](<VERIFICATION.md>)。回滚只停用此 bundle，保留聊天和计算产物，不切换其他功能。
