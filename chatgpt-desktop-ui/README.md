# 配色与消息样式

适用于 DSH **0.2.1-rc.2**。

> 这是 koishi 的自用设定，未做通用化。实际使用前，请在 DSH **创造模式**下按自己的需求检查、调整并测试，再通过官方插件管理器安装。创造模式不等于权限或沙箱模式；完整使用前说明见[仓库首页](<../README.md>)。

- **配色**：深蓝紫暗色、紫灰层级和浅灰文字；输入框、任务／审批条、文件卡、工具输出、按钮、菜单与侧边栏随主题换色，结构不变；警告文字、状态点和差异增删色保留。提供对应浅色配色。
- **用户消息**：右对齐圆角气泡、文本复制和时间戳。时间显示到分钟，悬停可查看完整时间；纯附件消息不显示空文本复制按钮。
- **展开思考**：正文左侧细线；原文与折叠逻辑不变。
- **字体**：字体、字号跟随官方设置，不单独指定。

安装／禁用：通过 DSH 插件管理器管理 `@koishi/dsh-chatgpt-message-style`，显示名“配色与消息样式”。禁用后恢复原主题层和消息渲染。

构建：`node scripts/build.mjs`。检查：`node --check lib/client.js`、`node --test test/*.test.mjs`。

验证记录：[VERIFICATION.md](VERIFICATION.md)。图标为原创。
