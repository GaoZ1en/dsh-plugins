- 完整回归 93/93 通过；类型检查、声明生成、Host/Client 构建通过。

## 当前限制

浏览器点击、深浅模式和渲染图标没有完整视觉验收；Host/Client 注册不等于点击验证。只针对固定宿主版本，不承诺跨版本。

技能开关不抹除历史对话，也不是文件访问沙箱；原生 MCP 开关影响同一 profile 的所有会话。列出的工具数是注册数量，不是持续健康证明。更详细的权限、凭据引用、回收区和持久状态边界见[使用说明](<README.md>)。
